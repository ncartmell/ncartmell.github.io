Projects

Open source and anything else I've put out publicly. Most of what I build is for work and lives in private repositories, so this is the smaller half of what I do — but it's the half you can actually read. All of it was written outside work, mostly to use libraries I don't touch day to day.

  • mtg-life-tracker Kotlin Multiplatform Compose

    A life tracker for Magic: The Gathering sharing one codebase across Android, iOS and desktop. The board rearranges itself for the number of players and turns each panel to face the person it belongs to. The rules — elimination thresholds, whether commander damage also costs life — live in a pure-Kotlin module with no UI dependency, so they test on any JDK with no simulator or Android SDK involved.

    Download for Android or macOS APK and .dmg, self-signed

  • ktor-task-api Kotlin Ktor Exposed PostgreSQL

    A small REST API for tasks. Ktor on Netty with kotlinx.serialization, Exposed over a HikariCP pool, and a consistent response envelope so successes and failures come back the same shape. Written to get familiar with Ktor and Exposed.

  • discord-bot Java JDA

    A Discord bot built on JDA, with a small client for the Bungie API behind it — item lookups by manifest hash, the milestones active this week, and lifetime stats for a player. Written to learn the library, and to have somewhere to point Destiny 2 questions.
